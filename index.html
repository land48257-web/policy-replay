Policy Replay

Dry-run a written support policy. Load two scans, OCR them locally in your browser, and compare where two pinned cases would be routed.

How it reads: this tool reads only simple, explicit English if/then routing rules of the form “If a damaged return includes a photo / has no photo, send it to <destination>.” for these two cases. Anything else gives no route. The source scan is always shown so a human can review it. Scans never leave this browser.
